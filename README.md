## 🤖 Implementation with AI: BMAD Method

We implement TP2 with the **BMAD Method**, so that AI agents (Claude Code, Codex/ChatGPT,
Gemini CLI) follow the group's plan instead of improvising.

**Start here (5 min):** [EN guide](docs/BMADGuideEN.md) · [Guia PT](docs/GuiaBMADPT.md)

1. `git pull` and install [uv](https://docs.astral.sh/uv/).
2. Open your agent in this folder: `claude`, `codex` or `gemini`.
3. Ask: **"bmad-help, what should I do next?"**

Rules for every agent: [`AGENTS.md`](AGENTS.md). Log every AI use in [`docs/ai-usage-log.md`](docs/ai-usage-log.md).
