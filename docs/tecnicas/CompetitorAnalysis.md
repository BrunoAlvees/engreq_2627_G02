# Technique 1 - Competitor Analysis

**Owner:** Jakub Piwko
**Status:** in progress

## Introduction

The AMAP/CSA movement in Portugal is small, and no Portuguese tool is built specifically for AMAPs. Mature solutions come from e.g. France, Switzerland and North America. In practice groups often rely on spreadsheets, forms and messaging apps.

We compared four solutions, one from each category:

- **AMAPJ:** a dedicated AMAP tool.
- **Juntagrico:** open-source CSA software.
- **Katuma (Open Food Network):** a platform available in Portugal.
- **Local Line:** a commercial SaaS.

## Comparison

| | AMAPJ | Juntagrico | Katuma (OFN) | Local Line |
|---|---|---|---|---|
| **Origin** | France | Switzerland | Spain/Portugal (OFN network) | Canada/USA |
| **Type** | AMAP management | CSA management | Short-supply-chain marketplace | Online store + subscriptions |
| **Price** | Free (open source) | Free (open source); free hosting for association members | Free (open source) | From 79$/month |
| **Users** | ~440 AMAPs (FR, BE, LU) | 25+ Swiss CSA cooperatives | 2,500+ enterprises across OFN | Farms in USA/Canada |
| **Key features** | Seasonal contracts, roles (member, referent, producer, treasurer), distributions, task sharing | Members, shares, subscriptions, deliveries, volunteer work coordination | Order cycles, producer catalogue, buying groups | CSA subscriptions, online payments, delivery routes, pickup points |
| **Focus** | Organisation | Organisation | Producer / hub | Producer |
| **Portuguese UI** | No | No | Yes | No |

## Key Points

- **Best conceptual fit:** organisation-focused tools (AMAPJ, Juntagrico) match AMAP Porto's needs best, but none is available in Portuguese.
- **Pricing model matters:** commission on baskets conflicts with AMAP ethics
- **Market gaps:**
  - Portuguese interface.
  - MB WAY or pay-at-pickup payments.
  - One shared instance for all Portuguese AMAPs.
  - Minimal effort required from farmers.
