# Técnica 2: Análise de documentação e do sistema atual

**Momento:** antes da elicitação (preparar entrevistas) e depois (verificar a cobertura dos requisitos)
**Responsável:** Bruno Alves
**Estado:** planeada

## Porquê esta técnica
- Na sessão de 23/09, o professor salientou que ainda não tinham sido feitas perguntas sobre os **documentos** do processo e que "os documentos dizem coisas que as pessoas não dizem nas entrevistas" (ex.: uma fatura contém cabeçalho, identificação do cliente, produtos linha a linha, total e forma de pagamento).
- Na entrevista de 29/09, a BioGoods referiu que organiza a AMAP com **Excel**. Esse é o **sistema atual** que a solução vai substituir.
- Permite recolher informação **sem gastar o tempo dos stakeholders** com o que já está escrito.

## Objetivos
1. **Recolher documentos reais** usados no funcionamento das AMAP/CSA.
2. **Identificar a informação que o sistema tem de guardar**: entidades e campos (coprodutor, produtor, AMAP, subscrição, cabaz, entrega, pagamento, fatura).
3. **Perceber como o Excel é usado hoje**: o que faz bem, o que falha e que tarefas são manuais ou sujeitas a erro.
4. **Identificar restrições legais e regulamentares** (faturação emitida por cada produtor, proteção de dados pessoais / RGPD).
5. **Preparar perguntas concretas** para a próxima entrevista a partir das lacunas encontradas.
6. **(Depois)** Verificar se os requisitos especificados **cobrem tudo o que o sistema atual faz**.

## Documentos a recolher
- [ ] Ficheiro(s) Excel usados pela BioGoods (versão anonimizada)
- [ ] Exemplo de fatura/recibo emitido por um produtor
- [ ] Ficha ou contrato de adesão à AMAP
- [ ] Carta de princípios das AMAP
- [ ] Regulamento interno de uma AMAP
- [ ] Listas de entregas / calendário de distribuição
- [ ] Legislação relevante (faturação, RGPD)

## Método
1. Pedir os documentos à BioGoods e pesquisar documentos públicos (sites de AMAP/CSA, rede AMAP).
2. Para cada documento, registar: origem, data, quem o produz, quem o usa e para quê.
3. Extrair os campos de informação para uma tabela comum.
4. Analisar o Excel: que folhas existem, que dados guarda, que cálculos faz, que problemas tem.
5. Listar dúvidas e lacunas, que passam a perguntas para a próxima entrevista.

## Resultados esperados (evidências)
- Lista de documentos analisados, com origem.
- Tabela de entidades e campos extraídos.
- Lista de pontos fortes e problemas do sistema atual.
- Lista de requisitos candidatos e restrições.
- Perguntas para a próxima entrevista.
- Registo de horas por elemento do grupo.
