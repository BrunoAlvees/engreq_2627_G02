# 3.3 Ciclos e subscrições

**Responsável:** Bruno Alves · **Atualizado em:** 12/11/2026 · **Estado:** rascunho para o relatório
**Fontes:** [RF03_CiclosSubscricoesPT.md](../requisitos/RF03_CiclosSubscricoesPT.md) (requisitos, fontes e estado) · critérios de aceitação em [12.4](12.4_AcceptanceCriteriaPT.md)

## 3.3.1 Descrição
Esta funcionalidade organiza o trabalho em ciclos de subscrição (hoje semestrais na AMAP Porto; trimestrais ou anuais noutras) e permite ao coprodutor subscrever, num só passo, os produtos de vários produtores, com as suas opções e exclusões. Substitui o Google Forms e a cópia por email que os coprodutores guardam para se lembrarem do que encomendaram, e dá a cada produtor os totais de que precisa para planear a produção.

**Prioridade: Alta** (5 dos seus 7 requisitos são Must).

*Tabela – Sequências estímulo/resposta da funcionalidade 3.3*

| Ação do utilizador (estímulo) | Resposta do sistema |
|---|---|
| A gestão da AMAP abre um ciclo com a sua duração e o prazo de subscrição | Avisa os membros ativos e aceita subscrições até ao prazo |
| O coprodutor escolhe cabazes, extras, variantes e datas de vários produtores | Mostra um resumo com os valores por produtor e, depois de confirmar, envia a subscrição por email |
| O coprodutor regista uma alergia ou um produto que não quer | Mostra a exclusão aos produtores que lhe entregam, para registarem a substituição |
| O coprodutor altera a encomenda durante o ciclo | Aceita a alteração se estiver dentro do prazo do produtor; caso contrário, explica porque não é possível |
| Chega um pedido de subscrição depois do prazo | Mantém-no pendente até a gestão o aprovar ou recusar |
| Aproxima-se o fim do ciclo | Pergunta ao coprodutor se vai renovar, com a encomenda anterior já preenchida |
| O produtor abre o plano de produção | Mostra os totais encomendados por produto, variante, data e AMAP |

### Especificação dos casos de uso
Os dois casos de uso principais estão detalhados abaixo.

*Tabela – Caso de uso: Subscrever um ciclo (FR-18)*

| | |
|---|---|
| **Nome** | Subscrever um ciclo |
| **Descrição** | Um coprodutor subscreve, num só passo, os produtos de vários produtores da sua AMAP para o ciclo seguinte. |
| **Atores** | Coprodutor (principal), produtor |
| **Pré-condições** | 1. O coprodutor é membro ativo da AMAP.<br>2. O ciclo está aberto e o prazo de subscrição ainda não passou. |
| **Fluxo principal** | 1. O coprodutor abre a página de subscrição do ciclo.<br>2. O sistema mostra os produtos de todos os produtores da AMAP, com preços, variantes e vagas disponíveis.<br>3. O coprodutor escolhe, para cada produto, a quantidade, a variante e, quando se aplica, as datas de entrega.<br>4. O sistema mostra um resumo com os produtos, as datas e o valor estimado por produtor.<br>5. O coprodutor confirma a subscrição.<br>6. O sistema regista a subscrição, envia uma confirmação por email e atualiza os totais de cada produtor. |
| **Fluxos alternativos** | A1 (passo 3): o coprodutor regista exclusões (alergias, intolerâncias, gostos); o sistema pede consentimento explícito para os dados de saúde.<br>A2 (passo 3): um produto já não tem vagas; o sistema propõe a sua lista de espera (FR-14). |
| **Exceções** | 1. O prazo já passou: o pedido fica pendente até a gestão o aprovar ou recusar.<br>2. O coprodutor sai antes de confirmar: nada é registado. |
| **Pós-condições** | 1. A subscrição fica ativa para o ciclo e visível para o coprodutor e para os produtores envolvidos.<br>2. Os pedidos de pagamento ficam agendados segundo as regras de pagamento de cada produtor (FR-31, funcionalidade 3.5). |

*Tabela – Caso de uso: Renovar subscrição (FR-22)*

| | |
|---|---|
| **Nome** | Renovar subscrição |
| **Descrição** | Antes do fim do ciclo, o coprodutor indica se vai continuar, para os produtores planearem o ciclo seguinte. |
| **Atores** | Coprodutor (principal), gestão da AMAP |
| **Pré-condições** | 1. O coprodutor tem uma subscrição ativa.<br>2. Chegou a antecedência de renovação definida pela AMAP (ex.: 3 meses antes do novo ciclo). |
| **Fluxo principal** | 1. O sistema avisa o coprodutor de que a renovação está aberta.<br>2. O coprodutor abre a renovação, com a encomenda anterior já preenchida.<br>3. O coprodutor mantém ou ajusta os produtos.<br>4. O coprodutor confirma que vai renovar.<br>5. O sistema regista a resposta e soma-a aos totais dos produtores para o ciclo seguinte. |
| **Fluxos alternativos** | A1 (passo 4): o coprodutor indica que não vai renovar; o sistema regista-o e avisa a gestão, que pode oferecer a vaga à lista de espera.<br>A2 (passo 5): a AMAP usa confirmação obrigatória; a resposta passa a ser a subscrição do ciclo seguinte. |
| **Exceções** | 1. O coprodutor não responde até ao prazo: com confirmação obrigatória, perde a vaga para a lista de espera; só com intenção, o sistema envia um lembrete. |
| **Pós-condições** | 1. Fica registada a intenção ou a confirmação do coprodutor para o ciclo seguinte. |

## 3.3.3 Requisitos funcionais

*Tabela – Requisitos funcionais da funcionalidade 3.3 (M = Must, S = Should, C = Could)*

| ID | Requisito | Ator | Prioridade |
|---|---|---|---|
| FR-17 | O sistema deve permitir criar ciclos de subscrição com duração configurável, data de abertura e data-limite de subscrição. | Gestão da AMAP | M |
| FR-18 | O sistema deve permitir ao coprodutor subscrever, num só passo, produtos de vários produtores da mesma AMAP, com as suas opções, e receber a confirmação. | Coprodutor | M |
| FR-19 | O sistema deve permitir ao coprodutor registar exclusões (alergias, intolerâncias, gostos) e ao produtor indicar a substituição feita. | Coprodutor, produtor | M |
| FR-20 | O sistema deve aplicar os prazos de subscrição e as regras de cada produtor para alterar encomendas durante o ciclo. | Coprodutor, produtor, gestão da AMAP | S |
| FR-21 | O sistema deve permitir ao coprodutor consultar, a qualquer momento, as subscrições em curso e o histórico. | Coprodutor | M |
| FR-22 | O sistema deve perguntar aos coprodutores, com antecedência, se renovam, partindo da encomenda anterior. | Coprodutor, gestão da AMAP | S |
| FR-23 | O sistema deve dar ao produtor a informação para planear a produção: totais encomendados e preferências agregadas. | Produtor | M |

*Os critérios de aceitação de cada requisito estão no Apêndice 12.4.*
