# Mockups da FAIR-AMAP

Mockups de alta fidelidade da aplicação FAIR-AMAP, para a secção 6.1 (interfaces com o utilizador) do SRS.
São exemplos: os produtos e preços vêm do formulário atual da AMAP UPTEC Baixa; os nomes de coprodutores são fictícios; `[N]`, `[valor]`, `[preço]` são valores que não conhecemos.

- `computador/`: 16 ecrãs (1440 px de largura)
- `telemovel/`: 14 ecrãs (390 px de largura)

As imagens estão a 2× (boa resolução para o relatório).
