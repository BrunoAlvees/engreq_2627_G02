# 2.3 Operating environment

**Owner:** Jakub Piwko · **Updated on:** 12/11/2026 · **Status:** draft for review
**Sources:** [RNF_AtributosQualidadeEN.md](../requisitos/RNF_AtributosQualidadeEN.md), dependencies in [2.5](2.5_PressupostosDependenciasEN.md), [2.4](2.4_RestricoesConcecaoImplementacaoEN.md), hardware and software interfaces in [6](6_ExternalInterfacesEN.md)

This section describes where FAIR-AMAP runs and is used: the users' devices, the server side, the places and times of use, and the other software it must work alongside. The requirements are only referenced here; their detail is in sections 6 and 7.

## 2.3.1 Users' devices

| Item | Environment | Ref. |
|---|---|---|
| Phones and tablets | Android and iPhone, through a web browser. The application can be installed on the home screen as a PWA, without app stores; the app explains how. | NFR-01 |
| Computers | Desktop or laptop with a web browser, mainly for producers and AMAP management (catalogue, calendar, payments, reports). | NFR-01 |
| Browsers | Current web browsers on mobile and desktop. **Group proposal (to confirm):** the two most recent major versions of Chrome, Safari, Firefox and Edge. | NFR-01, Hyp. |
| Push notifications | Supported through the PWA. **On iPhone, they only work if the PWA is installed on the home screen**; otherwise the user only receives email. | DE-03, NFR-15 |
| Printers (optional) | A4 printer to print the distribution sheet and bag labels as PDF. Not every AMAP has one; printing is optional. | FR-29, AS-08 |

## 2.3.2 Server side

| Item | Environment | Ref. |
|---|---|---|
| Hosting | Cloud hosting run by FAIR, preferably with servers in the European Union (GDPR). | DE-05, NFR-08, NFR-23 |
| Installation | One shared platform for all AMAPs (multi-AMAP), with each AMAP's data kept separate. | NFR-22 |
| Size | AMAPs with up to 200 co-producers, and several AMAPs in the same installation. | NFR-09, AS-06 |
| Backups | Daily backup, with a maximum loss of 24 hours of data. | NFR-11, DE-05 |
| Communication | All traffic between the browser and the servers uses HTTPS/TLS. | NFR-05 |

## 2.3.3 Places and times of use

| Item | Environment | Ref. |
|---|---|---|
| Geography | Portugal: a pilot in Portugal first (E-8); the AMAPs heard so far are in Porto (E-2, E-3). | E-8, NFR-13 |
| Language and formats | European Portuguese, ready for other languages (many co-producers are students or expatriates, E-8). Euros with VAT, dates as dd/mm/yyyy, Portuguese time zone. | NFR-13, NFR-14 |
| Distribution points | Spaces of host institutions (e.g. UPTEC, schools). Not every site has someone present during collection (E-2). Mobile coverage may be weak; collection confirmation can be stored on the phone and sent later. | AS-07, NFR-12 |
| Peak times | Distribution times of each AMAP (e.g. Tuesdays 17:30–19:30, D-A) and the last days of each subscription period. The system must be available in these periods; planned maintenance takes place outside them. | NFR-10, NFR-11 |

## 2.3.4 Software it must work with

| Software or service | How FAIR-AMAP works with it | Ref. |
|---|---|---|
| Email | Notifications, reminders and payment requests, through an email delivery service. | DE-02, NFR-15 |
| WhatsApp | Stays as a channel for informal communication between members. *(Could)* Individual notifications through the official WhatsApp Business API. | NFR-15, DE-04 |
| Spreadsheets (Excel and others) | Export of orders, deliveries and other data to CSV/XLSX; import of existing data when an AMAP starts using the platform. | NFR-16, FR-42, FR-45 |
| Licensed payment provider (e.g. Stripe, or MB Way through an aggregator) | Collects one payment per co-producer and splits it among producers. The system does not hold the money. | DE-01, NFR-17, NFR-19 |
| Producers' invoicing software | Each producer keeps invoicing in their own software. FAIR-AMAP does not issue invoices. | NFR-18 |

**Open points:**
- The supported browser versions are a group proposal and were not discussed with the client.
- "Portuguese time zone" should state whether the Azores time zone (one hour behind mainland Portugal) is also needed, if AMAPs there join the pilot.
