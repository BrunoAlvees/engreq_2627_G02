# Diagramas / Diagrams

**PT:** Os diagramas são escritos em **Mermaid** dentro de ficheiros `.md`. O GitHub mostra-os diretamente e as alterações aparecem no histórico como texto. Para passar para o SRS (Word), exportar uma imagem PNG: no [Mermaid Live Editor](https://mermaid.live) cola-se o código e faz-se *Actions → PNG*. Guardar o PNG nesta pasta com o mesmo nome do ficheiro. Diagramas mais complexos podem ser feitos no draw.io: guardar o `.drawio` e o `.png`.

**EN:** Diagrams are written in **Mermaid** inside `.md` files. GitHub renders them directly and changes show up in the history as text. To move them to the SRS (Word), export a PNG: paste the code into the [Mermaid Live Editor](https://mermaid.live) and use *Actions → PNG*. Save the PNG in this folder with the same name as the file. More complex diagrams can be made in draw.io: save both the `.drawio` and the `.png`.
